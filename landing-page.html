Get Started in 5 Minutes

Download the ISO, boot from USB, and deploy your first AI agent.

# 1. Download KIRAT OS ISO wget https://github.com/kirat-os/releases/download/v2.0.0/kirat-os-2.0.0.iso # 2. Write to USB (Linux) sudo dd if=kirat-os-2.0.0.iso of=/dev/sdX bs=4M status=progress # 3. Boot and install # Select "Install KIRAT OS" from GRUB menu # 4. After first boot, verify agents sudo systemctl status jitedasti-ai galinja-ai oysgja-ai suyarma-ai papa-ai aadhipati-ai
